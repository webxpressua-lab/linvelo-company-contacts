# Companies and Contacts Directory

A standalone searchable HTML directory generated from the supplied company data export.

## Features
- Search across source fields
- Filter by city, category, and email validation status
- Open a record to view all populated source fields

## Run locally
Open `index.html` in a modern browser. No build step or external dependencies are required.

## Source data
The page embeds the supplied contact records so search and filtering work offline. The repository is public and the records contain named business contacts and contact details.
