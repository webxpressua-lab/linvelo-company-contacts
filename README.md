# Companies and Contacts Directory

A standalone searchable HTML directory generated from the supplied company data export. This version contains only records whose city is Lingen, including source entries labeled “Lingen an der Ems” normalized to Lingen. Other cities are excluded.

## Features
- Search across source fields
- Filter by category and email validation status
- Open a record to view all populated source fields

## Run locally
Open `index.html` in a modern browser. No build step or external dependencies are required.

## Source data
The page embeds contact records from the supplied spreadsheet so search and filtering work offline. The repository and site are public and contain named business contacts and contact details.
